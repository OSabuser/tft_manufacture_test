# Исходники спрайтов резервного режима

Сюда кладутся **PNG-эталоны**. Из них паковщик генерирует
`firmware/tft_app/src/ui/fallback/sprites/<имя>.c`, которые вкомпиливаются в
образ. Коммитятся и исходники, и сгенерированное — как шрифты.

Требования к файлам, раскладка экрана и поведение при отсутствии спрайта —
[docs/tft_app/FALLBACK_SPRITES.md](../../../../docs/tft_app/FALLBACK_SPRITES.md).

**Имя файла — контракт.** Оно же имя символа в сгенерированном `.c` и имя в
логе; переименование на любом шаге рвёт связь. Ожидаемые имена:

| Файл | Что |
| --- | --- |
| `arrow_up.png` | стрелка вверх |
| `arrow_down.png` | стрелка вниз |
| `arrow_double.png` | двойная стрелка |
| `mode_lading.png` | погрузка |
| `mode_maintenance.png` | сервис / ревизия |
| `mode_seismic.png` | сейсмоопасность |
| `mode_overload.png` | перегруз |
| `mode_fire_alarm.png` | пожарная тревога |
| `mode_fireman.png` | режим пожарного |
| `mode_evacuation.png` | эвакуация |
| `mode_error.png` | авария |
| `dispatcher_calling.png` | вызов подан (диспетчер ещё не ответил) |
| `dispatcher_talking.png` | разговор с диспетчером идёт |

Файлы можно подвозить **по одному**: каждый заменяет свою деградацию
(примитив/текст), остальное продолжает работать. Прошивка собирается и при
полностью пустом каталоге.
