# Варианты DCD для `hil_sdram_stress`

Текстовые DCD в формате `tools/host/dcd_tool.py` (семантика — i.MX RT1050 RM Rev.4 §9.7.2).
При сборке `hil_sdram_stress` каждый файл превращается в C-массив и исполняется интерпретатором
`bsp_sdram_run_dcd()`. Выбор варианта — CLI-командой таргета.

Происхождение и расчёты — [SEMC_TIMING.md](../../../../docs/hardware/new_board_v3.2/SEMC_TIMING.md),
план — [PLAN.md](../../../../docs/hardware/new_board_v3.2/PLAN.md), фаза 0.

## Общие правила вариантов

- **Тактирование SEMC — только RMW своих полей** (`PFD_528.PFD2_*` или `PFD_480.PFD1_*`, `CBCDR.SEMC_*`) + ожидание
  `CDHIPR.SEMC_PODF_BUSY`. Legacy пишет `CBCDR = 0x00010D40` целиком — это ещё и `AHB_PODF=/4`,
  `IPG_PODF=/2`; в рантайме после `BOARD_BootClockRUN()` это уронило бы частоту ядра. В `legacy.txt`
  эта одна запись заменена на RMW, всё остальное — как в production.
- **Перед каждой IP-командой сбрасывается `SEMC_INTR`** (W1C). В legacy флаг `IPCMDDONE` после первой
  команды остаётся выставленным, и последующие check проходят сразу, не дожидаясь завершения.
- В кандидатах и `sdram_c` после включения PLL_SYS — `check_all_bits_set` на `LOCK`: не тактировать
  SEMC от незахваченной PLL (legacy и DCD EVK этого не ждут).
- Кандидаты муксят только `EMC_00..EMC_39` (как EVK): `EMC_40/41` на V3 — это EXT_IN2, им владеет `pin_mux`.
- **Между прогонами разных вариантов — сброс платы.** Вариант переконфигурирует живой SEMC
  и тактирование; прогон «поверх» предыдущего не эквивалентен холодному старту.
- **FRAC у PFD — только 12…35** (RM, `CCM_ANALOG_PFD_480/528`), иначе PFD не даёт такта. ≤133 МГц
  от PLL2 PFD2 не получить (FRAC 35 → 271,5 МГц: /2 = 135,8, /3 = 90,5), поэтому
  `candidate_dqsmd0_132mhz` берёт PLL3 PFD1. `dcd_tool` считает FRAC вне диапазона ошибкой.
- `candidate_no_refresh.txt` портит данные по определению — только для теста удержания.

## Проверка

`just build::test-tools` — все варианты разбираются, укладываются в 1768 байт, не пишут вне RM табл. 9-42, FRAC открытых PFD в 12…35;
`legacy.txt` сверяется с `bsp/generated/dcd/board/dcd.c` (отличие — только CBCDR).
