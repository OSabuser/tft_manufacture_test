# Отличия от legacy: клоки через RMW (как CLOCK_InitSysPfd/SetMux/SetDiv), без «мусорного» блока,
# SEMC_SendIPCommand() сбрасывает INTR перед каждой командой, финальный SDRAMCR3=0x50210A09 (из DCD EVK).

# CCGR0..6 = все вкл (sdram.c включает только SEMC — на SDRAM не влияет, для единообразия с кандидатами).
#
# Формат — tools/host/dcd_tool.py. Семантика — RM §9.7.2.
